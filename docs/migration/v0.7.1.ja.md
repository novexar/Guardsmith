## チェックリスト

### 1. extends を `@v0.7.1` に上げる(任意)

```
guard bump v0.7.1 --dry-run   # dry-run。計画と衝突予測を表示し、何も書かない
guard bump v0.7.1             # 適用。extends タグと guardsmith.vars.yaml も更新する
```

この dry-run が本リリースの主旨で、**新タグ**のマスターを解決し、本番が適用する計画を
そのまま表示したうえで何も書かない。`--write` なしの `guard sync` も dry-run だが、
基準は policy が **現在** 固定しているタグなので、bump の予見にはならない。

v0.7.0 との標準の差分は `init-project` の文言のみなので、クリーンなマージ 1 件で済み、
衝突は出ない見込み。`--dry-run` を使うには `@guardsmith/cli` を **0.6.1** へ上げる
(v0.7.1 の baseline 自体は 0.6.0 でも動く)。
