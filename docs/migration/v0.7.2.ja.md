## チェックリスト

### 1. extends を `@v0.7.2` に上げる(任意)

```
guard bump v0.7.2 --dry-run   # dry-run。計画と衝突予測を表示し、何も書かない
guard bump v0.7.2             # 適用。extends タグと guardsmith.vars.yaml も更新する
```

v0.7.1 との標準の差分は `docs/AGENTS.md`(2 行)と `init-project` のタグ例のみなので、
クリーンなマージで済む見込み。衝突が出るのは、PJ 側で `docs/AGENTS.md` のポリシー表の PM 行、
または PM に関する原則を書き換えている場合だけ。その場合は PJ の文言を残すか、新しい文言を
手で取り込む。

本リリースの取り込みは `@guardsmith/cli` 0.6.1 のままで足りる。0.6.2 との差は、
`guard new` 用に同梱する標準のみ。

- [ ] `guard bump v0.7.2 --dry-run` の出力を確認した

- [ ] 確認コマンド: `npx @guardsmith/cli lint`
- [ ] Action の `cli-version` / `release-tag` を固定している場合はそちらも上げた
