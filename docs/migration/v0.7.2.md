# v0.7.2 Migration Guide — incremental checklist for existing projects

**English** | [日本語](v0.7.2.ja.md)

Audience: projects operating on the v0.7.1 standards.
If you are migrating from an older version, apply the [v0.5.0](v0.5.0.md),
[v0.5.1](v0.5.1.md), [v0.5.2](v0.5.2.md), [v0.6.0](v0.6.0.md), [v0.7.0](v0.7.0.md) and
[v0.7.1](v0.7.1.md) guides first, then continue with this guide.

> **First, the baseline**: remote references are tag-pinned, so **nothing breaks if you do
> nothing**. Catching up is optional.

**There is nothing to do on the project side.** v0.7.2 changes one thing in the standards:
`docs/AGENTS.md` now names the PM (main session) model as "Claude Fable (latest)" instead
of a fixed version. The CLI's behaviour is unchanged.

## Checklist

### 1. Move the extends tag to `@v0.7.2` (optional)

```
guard bump v0.7.2 --dry-run   # dry-run: the plan and the predicted conflicts, writes nothing
guard bump v0.7.2             # applies it, and moves the extends tags and guardsmith.vars.yaml
```

The standards' diff against v0.7.1 is limited to `docs/AGENTS.md` (two lines) and the tag
examples in the `init-project` skill, so expect clean merges. A conflict appears only if
the project rewrote the PM row of the policy table or the PM principle in its own
`docs/AGENTS.md`; in that case keep the project's wording or adopt the new one by hand.

`@guardsmith/cli` 0.6.1 is enough to take this release in; 0.6.2 differs only in the
standards it bundles for `guard new`.

- [ ] Reviewed the `guard bump v0.7.2 --dry-run` output
- [ ] Ran `guard bump v0.7.2`
- [ ] Verify: `npx @guardsmith/cli lint`
- [ ] Bumped the Action's `cli-version` / `release-tag` if you pin them

### 2. Switch the PM session to the latest Fable (optional)

The policy no longer names a version. Select the latest Claude Fable for the main session
with `/model`; subagent models are unchanged.

- [ ] The main session runs on the latest Claude Fable

### 3. Rollback

Revert the `extends` tags in `guard.policy.yaml` to `@v0.7.1`, revert `standards:` in
`guardsmith.vars.yaml` (and the `CLAUDE.md` trailing stamp along with it — the two must
agree), and revert the merged file changes with git.

- [ ] Rollback steps shared with the team
