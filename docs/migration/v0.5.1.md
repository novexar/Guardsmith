# v0.5.1 Migration Guide — incremental checklist for existing projects

**English** | [日本語](v0.5.1.ja.md)

Audience: projects operating on the v0.5.0 standards.
If you are migrating from v0.2.1, apply the [v0.5.0 migration guide](v0.5.0.md) first,
then continue with this guide.

> **First, the baseline**: remote references are tag-pinned, so **nothing breaks if you do
> nothing**. Catching up is optional.

The delta from v0.5.0 is only the following two items:

## Checklist

### 1. Check the exclusion lines in .gitignore

Confirm that `.gitignore` contains the following two lines (projects generated by
v0.5.0's `guard new` already have them; add them if missing):

```gitignore
.guardsmith/
.claude/settings.local.json
```

`.guardsmith/` (CI result JSON) contains project-specific information such as the
repository name, branch names, and commit SHAs; `.claude/settings.local.json` contains
hook URLs and tokens — committing/pushing either is prohibited. The new baseline rule
`hygiene/guardsmith-artifacts-ignored` (warn) checks for these two lines.

- [ ] `.gitignore` contains the two lines above

### 2. Bump the extends tag to v0.5.1

```yaml
extends:
  - github:novexar/guardsmith//presets/baseline.yaml@v0.5.1 # ← changed from @v0.5.0
```

- [ ] Changed the extends tag to `@v0.5.1`
- [ ] Verify: `npx @guardsmith/cli lint` (no `hygiene/guardsmith-artifacts-ignored` warning)
