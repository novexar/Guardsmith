# v0.5.1 移行ガイド — 既存プロジェクトの差分適用チェックリスト

対象: v0.5.0 標準で運用中のプロジェクト。
v0.2.1 から移行する場合は、先に [v0.5.0 移行ガイド](v0.5.0.md) を適用してから本ガイドに進む。

> **まず前提**: リモート参照はタグ固定のため、**何もしなくても壊れない**。追随は任意。

v0.5.0 からの差分は以下の 2 点のみ:

## チェックリスト

### 1. .gitignore の除外行を確認する

`.gitignore` に次の 2 行があることを確認する(v0.5.0 の `guard new` 生成物は対応済み。
無ければ追記する):

```gitignore
.guardsmith/
.claude/settings.local.json
```

`.guardsmith/`(CI 結果 JSON)はリポジトリ名・ブランチ名・コミット SHA 等の PJ 固有情報を、
`.claude/settings.local.json` は hooks の URL・トークンを含むため、コミット/プッシュ禁止。
baseline 新ルール `hygiene/guardsmith-artifacts-ignored`(warn)がこの 2 行を検査する。

- [ ] `.gitignore` に上記 2 行がある

### 2. extends タグを v0.5.1 へ上げる

```yaml
extends:
  - github:novexar/guardsmith//presets/baseline.yaml@v0.5.1 # ← @v0.5.0 から変更
```

- [ ] extends のタグを `@v0.5.1` に変更した
- [ ] 確認コマンド: `npx @guardsmith/cli lint`(`hygiene/guardsmith-artifacts-ignored` の warn が出ないこと)
